# Minecraft Texture: Verdant Void Wizard

Verdant Void Wizard is a 64×64 pixel art Minecraft texture featuring a powerful purple and green wizard design with dark violet robes, glowing green magical accents, a spellbook-like chest motif, and a mystical void-inspired palette.

## Install

1. Download `assets/textures/powerful_wizard.svg`.
2. Open the SVG in an SVG-compatible image editor or browser.
3. Keep the artwork at its original 64×64 pixel dimensions.
4. Export or convert it to PNG if your Minecraft skin workflow requires a raster image.

## Use

1. Import the exported PNG into a Minecraft skin editor that supports 64×64 textures.
2. Check the character layout and adjust any areas required by your chosen skin editor.
3. Save the completed skin as a PNG.
4. Upload the PNG through Minecraft's skin customization menu or your preferred compatible platform.
